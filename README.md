# PRIMUM SCRIPTS - Автоматический установщик программ

**PRIMUM SCRIPTS** - это набор скриптов для автоматической установки необходимого программного обеспчения на Windows и macOS через пакетные менеджеры.

## 📋 Описание

Скрипт предоставляет удобный интерфейс для:
- Автоматической установки программ без подтверждения
- Интерактивной установки с подтверждением каждой программы
- Просмотра списка установленных/неустановленных программ
- Обновления уже установленных программ

## 🛠️ Поддерживаемые платформы

- **Windows**: Использует Chocolatey
- **macOS**: Использует Homebrew (в разработке)

## 📦 Структура проекта

```
primum-scripts/
├── install-software.bat        # Запускаемый файл для Windows
├── install-software.ps1        # Основной PowerShell скрипт
├── windows-software.json       # База данных программ для Windows
├── macos-software.json         # База данных программ для macOS
└── README.md                   # Документация
```

## ⚡ Быстрый старт

### Windows

1. **Скачайте все файлы** в одну папку
2. **Запустите** `install-software.bat` двойным кликом
3. **Выберите** нужный пункт меню:
   - `1` - Автоматическая установка всех программ
   - `2` - Интерактивная установка с подтверждением
   - `3` - Показать список установленных программ
   - `0` - Выход

### Альтернативный запуск через PowerShell

```powershell
# Перейти в папку со скриптом
cd "путь\к\папке\win-scripts"

# Запустить скрипт
powershell -NoProfile -ExecutionPolicy Bypass -File "install-software.ps1"
```

## 🎯 Функциональность

### 1. Автоматическая установка
- Устанавливает все программы из JSON файла без запросов
- Автоматически обновляет уже установленные программы
- Автоматически устанавливает Chocolatey при необходимости

### 2. Интерактивная установка
- Показывает информацию о каждой программе
- Для неустановленных программ спрашивает: "Установить?"
- Для установленных программ спрашивает: "Программа уже установлена. Обновить ее?"
- Ведет подсчет установленных/пропущенных программ

### 3. Список программ
- Показывает все программы по категориям
- Отмечает установленные ✓ и неустановленные ✗ программы
- Показывает способ установки (Chocolatey)

## 🔧 Настройка

### Добавление новых программ

Отредактируйте файл `windows-software.json`:

```json
{
  "name": "Название программы",
  "description": "Описание программы",
  "choco_id": "chocolatey-package-id",
  "official_url": "https://official-website.com/",
  "installer_type": "exe"
}
```

### Изменение категорий

Программы организованы по категориям в JSON файле. Вы можете:
- Добавлять новые категории
- Перемещать программы между категориями
- Изменять описания

## ⚠️ Важные замечания

### 🔤 Кодировка файлов

**КРИТИЧЕСКИ ВАЖНО**: Для корректного отображения русского текста в терминале все файлы должны быть сохранены в кодировке **UTF-16 LE** (UTF-16 Little Endian).

#### Как проверить/изменить кодировку:

**Visual Studio Code:**
1. Откройте файл `.ps1`
2. В нижней панели справа найдите текущую кодировку
3. Нажмите на неё и выберите "Save with Encoding"
4. Выберите "UTF-16 LE"

**Notepad++:**
1. Откройте файл
2. Меню "Кодировки" → "Кодировать в UTF-16 LE"
3. Сохраните файл

**Блокнот Windows:**
1. "Сохранить как"
2. В поле "Кодировка" выберите "Unicode"

## 🐛 Устранение неполадок

### Проблема: Крякозябры в тексте
**Решение**: Убедитесь, что файл `.ps1` сохранен в кодировке UTF-16 LE

### Проблема: Ошибка ExecutionPolicy
**Решение**: Запустите PowerShell от администратора и выполните:
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### Проблема: Chocolatey не устанавливается
**Решение**: 
1. Проверьте подключение к интернету
2. Запустите PowerShell от администратора
3. Убедитесь, что TLS 1.2 включен

### Проблема: Программа не найдена в Chocolatey
**Решение**: Скрипт предложит ссылку для ручной установки
